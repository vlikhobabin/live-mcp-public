# AIDataRead: чтение данных из 1С для PHP-разработчика

Сервис `ai-data-read` — это HTTP-сервис расширения `AIDataRead`, опубликованный
в базе 1С. Вы отправляете ему обычный HTTP `POST` с текстом запроса на языке 1С
и получаете JSON. SOAP, COM и клиент 1С не нужны: только `curl` и HTTP Basic.

Доступ только на чтение: сервис выполняет `ВЫБРАТЬ`-запросы, изменения данных
отклоняются.

## 0. Что нужно

* PHP 8.0+ с расширением `curl`.
* Базовый URL сервиса: `https://1c.example/base/hs/ai-data-read` — подставьте
  адрес своей публикации.
* Логин: `read_user`, пароль выдаётся отдельно (в коде не хранить).
* Аутентификация — HTTP Basic (логин/пароль пользователя ИБ); cookies и токены
  не нужны. Если публикация дополнительно закрыта внешним шлюзом с Basic-
  аутентификацией, учётная запись для шлюза и для 1С должна совпадать: сервис
  получает один заголовок `Authorization`.

## 1. Подключение и проверка доступности

`GET {base}/ping/`

```bash
curl -u 'read_user:<пароль>' \
  https://1c.example/base/hs/ai-data-read/ping/
```

Успех — HTTP 200 и JSON:

```json
{"success": true, "service": "ai-data-read", "status": "ok", "version": "0.2.0"}
```

## 2. Список всех складов (только элементы, код и наименование)

Запрос:

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Ссылка КАК Код,
    Наименование КАК Наименование
ИЗ Справочник.Склады
ГДЕ НЕ ЭтоГруппа И НЕ ПометкаУдаления
УПОРЯДОЧИТЬ ПО Наименование
```

HTTP-запрос:

```
POST {base}/v1/query/execute/
Content-Type: application/json; charset=utf-8
Authorization: Basic ...

{"query": {"text": "ВЫБРАТЬ РАЗРЕШЕННЫЕ ..."}}
```

Ответ (фрагмент):

```json
{
  "success": true,
  "result": {
    "rowCount": 1,
    "rows": [
      {
        "Код": {"type": "reference", "typeName": "Справочник.Склады",
                "uuid": "11111111-1111-1111-1111-111111111111",
                "presentation": "Склад 1",
                "empty": false},
        "Наименование": "Склад 1"
      }
    ]
  }
}
```

> **Важно про «код».** В проверенной конфигурации у справочника `Склады`
> **нет реквизита `Код`** (справочник без кода). Роль кода играет UUID ссылки:
> в запросе он выводится под псевдонимом `Код`, в JSON лежит в `Код.uuid`.
> Именно этот UUID передавайте в шаг 3. Человекочитаемого кода у склада здесь
> нет.

## 3. Все реквизиты склада по указанному коду (UUID)

Запрос с параметром `&Ссылка`:

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Ссылка КАК Ссылка,
    Наименование КАК Наименование,
    ЭтоГруппа КАК ЭтоГруппа,
    Родитель КАК Родитель,
    ТипСклада КАК ТипСклада,
    Подразделение КАК Подразделение,
    ПометкаУдаления КАК ПометкаУдаления,
    Предопределенный КАК Предопределенный,
    ВерсияДанных КАК ВерсияДанных
ИЗ Справочник.Склады
ГДЕ Ссылка = &Ссылка
```

Тело запроса с параметром:

```json
{
  "query": {"text": "ВЫБРАТЬ РАЗРЕШЕННЫЕ ..."},
  "parameters": [
    {"name": "Ссылка", "valueType": "reference",
     "typeName": "Справочник.Склады", "uuid": "11111111-1111-1111-1111-111111111111"}
  ]
}
```

Ответ — ровно одна строка `result.rows[0]` со всеми реквизитами.

### Реквизиты справочника (пример конфигурации)

| Поле | Тип | Комментарий |
|---|---|---|
| `Ссылка` | ссылка | UUID — он же «код» |
| `Наименование` | строка | |
| `ЭтоГруппа` | булево | `true` — группа, `false` — склад |
| `Родитель` | ссылка | родительская группа |
| `ТипСклада` | перечисление | `Перечисление.ТипыСкладов`, пример значения — «Оптовый склад» |
| `Подразделение` | ссылка | `Справочник.СтруктураПредприятия` |
| `ПометкаУдаления` | булево | |
| `Предопределенный` | булево | системный |
| `ВерсияДанных` | строка Base64 | системный |

`Код` отсутствует. Сервис не отдаёт метаданные: список реквизитов фиксируется
текстом запроса. Если в конфигурации появятся новые реквизиты — их нужно
добавить в запрос.

## 4. Остатки по складам

Остатки берутся из регистра накопления `ТоварыНаСкладах` через виртуальную
таблицу `Остатки`. Дата **не указывается** — таблица возвращает актуальные
остатки на момент запроса.

### 4.1. По всем складам (без фильтра)

```sql
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Склад КАК Склад,
    Номенклатура КАК Номенклатура,
    Характеристика КАК Характеристика,
    ВНаличииОстаток КАК Остаток
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки
ГДЕ ВНаличииОстаток <> 0
УПОРЯДОЧИТЬ ПО Склад, Номенклатура
```

### 4.2. По одному складу

Добавьте условие `И Склад = &Склад`:

```sql
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Склад КАК Склад,
    Номенклатура КАК Номенклатура,
    Характеристика КАК Характеристика,
    ВНаличииОстаток КАК Остаток
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки
ГДЕ ВНаличииОстаток <> 0
    И Склад = &Склад
УПОРЯДОЧИТЬ ПО Номенклатура
```

Параметр — ссылка на склад из шага 2:

```json
{
  "query": { "text": "ВЫБРАТЬ ... И Склад = &Склад ..." },
  "parameters": [
    { "name": "Склад", "valueType": "reference",
      "typeName": "Справочник.Склады", "uuid": "<uuid склада>" }
  ],
  "limits": { "maxRows": 5000 }
}
```

### 4.3. PHP

В классе из раздела 7 есть готовые методы:

```php
$stockAll = $api->getAllStock();                      // все склады
$stockOne = $api->getWarehouseStock($warehouseUuid);  // один склад
```

Строка ответа выглядит так:

```json
{
  "Склад": {"type": "reference", "typeName": "Справочник.Склады",
            "uuid": "...", "presentation": "Склад 1", "empty": false},
  "Номенклатура": {"type": "reference", "typeName": "Справочник.Номенклатура",
                   "uuid": "...", "presentation": "Товар 1", "empty": false},
  "Характеристика": {"type": "reference", "typeName": "Справочник.ХарактеристикиНоменклатуры",
                     "uuid": "00000000-0000-0000-0000-000000000000", "presentation": "", "empty": true},
  "Остаток": 10
}
```

* `Остаток` — **число** (`5.5`, `10`), не строка.
* Название склада/номенклатуры — `presentation`, код — `uuid`.
* `Характеристика` чаще пустая (`empty: true`); если не нужна, уберите её из
  запроса.
* Нужны и нулевые строки — уберите `ГДЕ ВНаличииОстаток <> 0`.

Быстрая проверка без PHP:

```bash
curl -s -u 'read_user:<пароль>' \
  -H 'Content-Type: application/json; charset=utf-8' \
  -d '{"query":{"text":"ВЫБРАТЬ РАЗРЕШЕННЫЕ Склад, Номенклатура, ВНаличииОстаток КАК Остаток ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки ГДЕ ВНаличииОстаток <> 0"}}' \
  https://1c.example/base/hs/ai-data-read/v1/query/execute/
```

## 5. Как читать значения в JSON

| Тип 1С | JSON | Как достать |
|---|---|---|
| строка | `"..."` | как есть |
| число | `1` | как есть |
| булево | `true` / `false` | как есть |
| дата | `"2026-01-31T00:00:00"` | как строка ISO |
| ссылка | `{"type":"reference","typeName":"...","uuid":"...","presentation":"...","empty":false}` | `$v['uuid']`, `$v['presentation']` |
| перечисление | `{"type":"enum","typeName":"...","name":"...","presentation":"...","empty":false}` | `$v['name']`, `$v['presentation']` |
| пустая ссылка | `{"uuid":"00000000-...","empty":true}` | проверяйте `empty` |
| пусто (`Неопределено`/`Null`) | `null` | проверяйте `=== null` |

Пример: `$row['Родитель']['presentation']`, `$row['ТипСклада']['presentation']`.

## 6. Ошибки и ограничения

| HTTP | Что значит |
|---|---|
| `200` | успех (всегда проверяйте `success === true`) |
| `400` | ошибка запроса: JSON `{"success":false,"code":"...","message":"..."}` |
| `401` | неверный логин/пароль |
| `403` | у учётной записи нет права `Use` на метод (ответ — текст, не JSON) |
| `404` | неверный путь: в URL должен быть `/hs/ai-data-read` |

Частые коды `400`:

* `query_parse_error` — ошибка в тексте запроса (чаще всего неверное имя
  реквизита или таблицы);
* `allowed_select_required` — забыли `ВЫБРАТЬ РАЗРЕШЕННЫЕ`;
* `invalid_parameters` / `unknown_reference_type` — ошибка в `parameters`.

Ограничения на один запрос: до 5000 строк, 200 колонок, 200 000 ячеек,
4 МБ ответа; `limits.maxRows` можно уменьшить, увеличить сверх максимума нельзя.

## 7. Полный рабочий пример

```php
<?php
declare(strict_types=1);

final class AIDataRead
{
    public function __construct(
        private string $baseUrl,
        private string $user,
        private string $password,
        private int $timeoutSeconds = 60,
    ) {
        $this->baseUrl = rtrim($baseUrl, '/');
    }

    public function ping(): array
    {
        return $this->call('GET', '/ping/');
    }

    public function query(string $text, array $parameters = [], array $limits = []): array
    {
        $body = ['query' => ['text' => $text]];
        if ($parameters !== []) {
            $body['parameters'] = $parameters;
        }
        if ($limits !== []) {
            $body['limits'] = $limits;
        }
        return $this->call('POST', '/v1/query/execute/', $body);
    }

    /** Остатки по всем складам (актуальные, без даты). */
    public function getAllStock(int $maxRows = 5000): array
    {
        return $this->query(<<<'BSL'
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Склад КАК Склад,
    Номенклатура КАК Номенклатура,
    Характеристика КАК Характеристика,
    ВНаличииОстаток КАК Остаток
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки
ГДЕ ВНаличииОстаток <> 0
УПОРЯДОЧИТЬ ПО Склад, Номенклатура
BSL, [], ['maxRows' => $maxRows])['result']['rows'];
    }

    /** Остатки по одному складу (актуальные, без даты). */
    public function getWarehouseStock(string $warehouseUuid, int $maxRows = 5000): array
    {
        return $this->query(<<<'BSL'
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Склад КАК Склад,
    Номенклатура КАК Номенклатура,
    Характеристика КАК Характеристика,
    ВНаличииОстаток КАК Остаток
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки
ГДЕ ВНаличииОстаток <> 0
    И Склад = &Склад
УПОРЯДОЧИТЬ ПО Номенклатура
BSL, [[
            'name'      => 'Склад',
            'valueType' => 'reference',
            'typeName'  => 'Справочник.Склады',
            'uuid'      => $warehouseUuid,
        ]], ['maxRows' => $maxRows])['result']['rows'];
    }

    private function call(string $method, string $path, ?array $body = null): array
    {
        $ch = curl_init($this->baseUrl . $path);
        if ($ch === false) {
            throw new RuntimeException('curl_init failed');
        }
        $headers = ['Accept: application/json'];
        $options = [
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_HTTPAUTH       => CURLAUTH_BASIC,
            CURLOPT_USERPWD        => $this->user . ':' . $this->password,
            CURLOPT_CONNECTTIMEOUT => 10,
            CURLOPT_TIMEOUT        => $this->timeoutSeconds,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
        ];
        if ($method === 'POST') {
            $headers[] = 'Content-Type: application/json; charset=utf-8';
            $options[CURLOPT_POST] = true;
            $options[CURLOPT_POSTFIELDS] = json_encode($body, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
        }
        $options[CURLOPT_HTTPHEADER] = $headers;
        curl_setopt_array($ch, $options);

        $raw = curl_exec($ch);
        if ($raw === false) {
            $error = curl_error($ch);
            curl_close($ch);
            throw new RuntimeException('HTTP transport error: ' . $error);
        }
        $status = (int) curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
        curl_close($ch);

        $data = json_decode($raw, true);
        if (!is_array($data)) {
            throw new RuntimeException("Non-JSON response (HTTP {$status}): " . substr($raw, 0, 300));
        }
        if ($status >= 400) {
            throw new RuntimeException(sprintf(
                'HTTP %d, code=%s, message=%s',
                $status,
                $data['code'] ?? '-',
                $data['message'] ?? '-'
            ));
        }
        return $data;
    }
}

// 1. Подключение и проверка доступности
$api = new AIDataRead(
    'https://1c.example/base/hs/ai-data-read',
    'read_user',
    getenv('AIDR_PASSWORD') ?: throw new RuntimeException('AIDR_PASSWORD is not set'),
);
$ping = $api->ping();
if (($ping['success'] ?? false) !== true) {
    throw new RuntimeException('Сервис недоступен');
}

// 2. Список складов: только элементы, код (UUID) и наименование
$list = $api->query(<<<'BSL'
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Ссылка КАК Код,
    Наименование КАК Наименование
ИЗ Справочник.Склады
ГДЕ НЕ ЭтоГруппа И НЕ ПометкаУдаления
УПОРЯДОЧИТЬ ПО Наименование
BSL);
$warehouses = [];
foreach ($list['result']['rows'] as $row) {
    $warehouses[] = [
        'code' => $row['Код']['uuid'],
        'name' => $row['Наименование'],
    ];
}

// 3. Все реквизиты склада по коду
$code = $warehouses[0]['code'];
$detail = $api->query(<<<'BSL'
ВЫБРАТЬ РАЗРЕШЕННЫЕ
    Ссылка КАК Ссылка,
    Наименование КАК Наименование,
    ЭтоГруппа КАК ЭтоГруппа,
    Родитель КАК Родитель,
    ТипСклада КАК ТипСклада,
    Подразделение КАК Подразделение,
    ПометкаУдаления КАК ПометкаУдаления,
    Предопределенный КАК Предопределенный,
    ВерсияДанных КАК ВерсияДанных
ИЗ Справочник.Склады
ГДЕ Ссылка = &Ссылка
BSL, [[
    'name'      => 'Ссылка',
    'valueType' => 'reference',
    'typeName'  => 'Справочник.Склады',
    'uuid'      => $code,
]]);
$row = $detail['result']['rows'][0] ?? null;
if ($row === null) {
    throw new RuntimeException("Склад с кодом {$code} не найден");
}
print_r($row);

// 4. Остатки: все склады и один склад (актуальные, без даты)
$stockAll = $api->getAllStock();
$stockOne = $api->getWarehouseStock('11111111-1111-1111-1111-111111111111'); // склад с остатками
echo 'строк остатков по всем складам: ' . count($stockAll) . "\n";
echo 'строк остатков по складу: ' . count($stockOne) . "\n";
```

Запуск:

```bash
AIDR_PASSWORD='<пароль>' php example.php
```

## 8. Полезные замечания

* В каждом запросе обязателен `ВЫБРАТЬ РАЗРЕШЕННЫЕ`, иначе сервис вернёт
  `allowed_select_required`.
* `ВЫБРАТЬ *` через этот сервис **не работает**: платформа принимает `*`, но
  результат содержит служебное значение типа «Результат запроса», и сервис
  отвечает `400 unsupported_result_value`. Перечисляйте поля явно (список — в
  разделе 3).
* Только один `SELECT`-запрос за вызов; изменения данных запрещены. (Сервис
  принимает и пакет запросов с временными таблицами, но возвращает один
  результат; для чтения справочника достаточно одного `SELECT`.)
* Подставляйте значения только через `parameters` (как `&Ссылка` в примере),
  не склеивайте текст запроса — это защита от инъекций.
* Пароль храните в переменной окружения или секрете, не в коде.
* Если нужны только активные элементы без групп: `ГДЕ НЕ ЭтоГруппа И НЕ ПометкаУдаления`.
* Поиск по наименованию: добавьте `И Наименование ПОДОБНО &Маска` и передайте
  параметр `{"name":"Маска","valueType":"string","value":"%Склад%"}`.
